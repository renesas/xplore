Xplore Quick Start Guide

Use this guide to open an Xplore project in Renesas 365, build and debug it, save a modified solution, and troubleshoot common debug or flashing errors.

Target Devices

FPB-RA0L1FPB-RA2E3FPB-RA4E2FPB-RA6E2FPB-RA8E1

Contents

  2. Building and Debugging the Project

1. Navigation to R365 Project

  1. Select either Software BB or Solution Hub from the Xplore landing page to choose an application based on a Software Building Block or a hands-on solution.

    Figure 1. Software Building Blocks in Xplore Hub

  2. Select Experience Now.

    Figure 2. Xplore Landing Page

  3. Click the Software block to open the Web IDE.

    Figure 3. Opening the Web IDE

2. Building and Debugging the Project

  1. When the IDE is ready, build the project by clicking Build.

    Figure 4. Building the Project

  2. When the build is complete, select the Debug view and choose Renesas WebUSB J-Link GDB Debugging. Click the green arrow to connect to J-Link.

    Figure 5. Debugging

  3. Click the green arrow to connect to the board and start debugging.

    Figure 6. Connecting to the Board

  4. Once flashing is complete, click the blue Continue icon to run the project on the board.

    Figure 7. Running the Project

3. Modifying and Saving the Project

  1. Make changes to the files, then build, flash, and run the project as described in Section 2.
  2. The modified project can be renamed and its properties edited through Renesas 365.

    Figure 8. R365 New Solution View

4. Troubleshooting Debug and Flashing Errors

4.1 “gdbserver” Error

  1. If a gdbserver error appears, follow Section 1.1.1 of Debugging a Project - Renesas VS Code Web Extensions to switch the USB driver to WinUSB mode, or use the steps below.

    Figure 9. gdbserver Error

  2. Download and install J-Link WinUSB Lite using the appropriate installer listed in the source Quick Start Guide.
  3. If the switcher reports No probes found, continue with the driver steps below.

    Figure 10. J-Link WinUSB Switcher - No Probes Found

  4. Download and install the J-Link Software and Documentation Pack from the SEGGER website.
  5. Open Device Manager and locate the USB device under Other devices.
  6. Navigate to C:\Program Files\SEGGER\JLink\USBDriver\ and run InstDrivers.exe.

    Figure 11. Updating the Driver

  7. Select the probe in J-Link WinUSB Switcher and click Switch to WinUSB.

    Figure 12. Switching to WinUSB

  8. Click Yes to confirm the driver update.

    Figure 13. Driver Update Confirmation

  9. The board is now ready for flashing and debugging.
